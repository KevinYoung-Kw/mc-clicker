# V1.8.1 · 命令方块与信标

已随 V1.8.1（`e25e765`）发布，与建筑收纳属于同一批交付。

## 核查结论

原命令方块只提供固定策略：工作耗电 ×0.8、运输能力 ×1.4、成交能力 ×1.4。并不会自动选择策略；原“优先完成订单”不等于专门调整订单分配。比较器负责手动供电优先级，前期的自动接电也不承担跨世界调度。

命令方块保留后期解锁和原价格，不通过额外叠加倍率制造新作用。新增跨世界自动调度，每八秒在游戏模拟内作一次决策：

1. 世界工程尚未完成时，优先选择交付进度最低的可用世界；同进度时优先积压较多者。
2. 尚无工程或工程完成后，根据库存相对于运输／成交能力的积压时间选择支援世界。
3. 成品积压时加快成交；原料积压且运输弱于加工时加快运输；其余情况节能生产。
4. 信标联动到选中的世界，运输为瓶颈时强化物流，其余强化生产。仍须接电；没有信标时只应用策略。

计算瓶颈时先扣除当前调度及信标自身的倍率，避免刚加速运输，下次又因为运输变快而撤回强化。

固定策略仍作用于三个世界，联动信标只强化一个世界。它是便利的自动选择，不保证比玩家针对瓶颈手动操作更快；缺岗位、断电、无可达路径等问题仍须处理。末影箱目的地、岗位、线路和订单比例不被改写。

## 操作与视觉

- 从世界点命令方块，直接选择策略；点信标可切换强化世界及生产／物流。工业页复用同一套控制。
- 自动调度时，信标显示正在支援的世界，并提供命令方块入口。关闭自动后恢复原手动信标设置。
- 光束：主世界绿色、下界橙红、末地紫色，按实际强化目标变化；断电仍熄灭。材质实例独立，不影响预览或其他模型。
- 状态更新只修改文本；不按倒计时重建卡片。选择器沿用像素下拉菜单。
- 修复 WebKit 画布触摸后的兼容点击穿到新面板按钮：画布保留 Pointer 手势处理，阻止浏览器再合成一次点击。
