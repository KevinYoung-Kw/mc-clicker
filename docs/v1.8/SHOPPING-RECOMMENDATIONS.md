# V1.8.2 · 商城推荐与升级发现

已随 V1.8.2（`7172d4a`）发布，GitHub 与腾讯云同步。

- 「发现」同时列出新商品和已有设施的升级／改造。邮政建成后即可看见邮政升级，无需先买完所有新商品。
- 「按进度推荐」继续使用现有发展目标和岗位／接电指引；下一件新商品或解锁所需的本体升级优先，其后交替呈现可用升级与新商品，同组按本次价格排列。这是发现性推荐，不宣称是收益最优解。
- 「绿宝石从低到高」将新商品和升级按下一次实际价格统一排序，不拿最初购买价替代升级价格。待解锁新商品另列；条件不足的改造留在详情。
- 每座设施列出一项当前价格最低的可用改进，可在本体未满级时推荐已解锁的改造。点改造直达对应展开项，点邮政直达升级页。「已购买」共用同一报价与排序。
- 扩地、居民招募、已收纳和已完成的设施不混入可用升级推荐。金额和短期货物波动不重排列表；购买、改造、邮政等级和收纳状态变化后更新。
- 复用像素下拉和单行分隔，无新增弹窗。排序偏好保存在当前浏览器的 `mc-clicker-shop-order`，关闭面板和刷新后保留；这是本机列表偏好，不更改游戏存档字段、经济数值或已购资格。
