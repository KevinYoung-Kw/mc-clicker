# V1.8.3 · 工业、村庄与建筑管理收尾

2026-09-10，已随 V1.8.3 发布，提交 `0324bfc`。GitHub 与腾讯云同步；[线上验收](qa/live-1.8.3/README.md)。

## 发现与修改

- 工业页顶部的「仓库」「控制台」以前直接触发收纳，名字却像进入管理。改为齿轮＋设施名，进入对应详情；收纳仍通过详情的箱子图标操作。工业和村庄共用紧凑的一行「整理建筑」工具栏。
- 收纳受阻以前只弹出短暂通知，玩家不知道收纳的用途或下一步。现在所有设施／住宅使用统一说明：从地图移走、保留什么、在哪免费摆回。受阻时持续显示原因，不显示可以确认的假按钮。
- 储电提示显示收纳后的容量和当前电量，不再要求玩家含糊地“耗光电力”。提供查看电力以及直接搬动；村民岗位、物流和住宅住户有对应处理入口。
- 住宅的定位、搬动、收纳集中到标题右侧，复用设施图标按钮；入住安排保留原操作。工业设备与农牧任务改为单行分隔，避免重复卡片边框。
- 确认时重新检查状态；如果有新工作或货物，回到说明界面。未放弃电量、热量、库存、等级或住户；收纳条件与生产数值没有放宽。
