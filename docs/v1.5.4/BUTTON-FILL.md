# V1.5.4：采集按钮内的连击进度

按用户修正，将独立连击条删除。采集按钮背景本身从左向右填充；连续采集积累倍率，松手后填充随倍率逐渐退回，归零恢复按钮原样。

没有新增一行文案、倍率数字或按钮。按钮原有的「采集／本次收益／点按或按住」保持原位，填充在文字下方，不拦截点按、长按、拖动和空格输入。

- 填充读取 `miningCombo(state).progress`；最高 ×1.60、铁镐解锁长按、衔接时间及收益规则沿用 V1.5.3。
- 按钮在松手后仍保留并衰减填充，不使用原来的定时播放假进度。
- 填充使用当前主题颜色；系统或游戏的减少动态设置关闭插值过渡。
- 木镐、铁镐的旁白改为指向「采集按钮」，去掉「下面那条」的旧说明。
- 主存档与子系统版本不变，不新增进度存档。

验证：5 项相关规则测试通过；Chromium 1440、WebKit 390、Chromium 320 检查按钮填满、松手回退、恢复基础、按钮位置／高度、四主题和减少动态。320px 使用 CDP 真实触控；其余为浏览器输入模拟。正式构建通过，原有大于 500 kB 的包体提示保留。
