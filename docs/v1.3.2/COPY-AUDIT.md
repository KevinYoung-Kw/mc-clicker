# V1.3.2 文案核对表

原则：先说用途与操作，再说明收益、限制和必要数值。不以删字为目标，不更改价格、生产规则、购买条件或已购资格。文案以当前模拟规则为准。

## 核对范围

- 98 个主目录项目、40 件网页装扮、52 个设施改造、10 种村民岗位（含自由活动）、5 种观象台仪器。
- 商品卡和详情共用说明；村民首购文案不再被动态基础收入句子覆盖。
- 同步检查操作指南、村庄与电力管理、自动化、直播人员、唱片、装扮、邮箱、工程、设置和购买受阻提示。
- 两封作者来信、六张唱片的名称与风格简介、分享纪念卡的装饰性标题，以及清楚的短状态（例如“等待供电”“已满级”）保留。
- “定位”改为昵称右侧按钮；“招募村民”不再显示为“升级”。
