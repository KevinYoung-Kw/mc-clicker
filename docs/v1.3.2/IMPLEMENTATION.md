# V1.3.2 · 看得懂的说明与统一选择菜单

本轮按用户修正执行：重点是把文案写得直白、容易理解，不是减少字数。

## 改动

- 村民和铜傀儡的定位图标放在昵称右侧，沿用现有室外/室内镜头定位。轮休村民没有不存在的世界定位入口。
- 岗位菜单逐项展示职业、工作地点、作用、在岗人数和不可分配的原因。满员与运货中的限制读取原有岗位规则；每次打开都会重新核对。
- 统一岗位、个人培训、轮休换班、傀儡工作方式、自动化分配、供电优先级、信标、末影箱、命令方块、天气、分享卡面和邮件类型的下拉菜单。原生 select 继续承载数值与 change 事件，未创建第二套业务状态。
- 选择菜单适配默认外观与四套主题，使用方形边框、像素箭头、触屏可滚动选项、键盘操作与焦点恢复。菜单可以向上展开；设备状态变化引发面板更新时，保留正在看的菜单、选项和滚动位置。
- 改写 98 个主目录项目、40 件网页装扮和 5 种观象台仪器的作用说明；52 项改造的效果改为基于现有数据生成的百分比描述，单独说明耗电。
- 同步改写村民岗位、操作指南、生产与电力管理、直播、唱片、工程、邮箱、设置和部分失败原因。唱片播放、乐师演出和音序师加速分别说明；奖励继续按点击领取时的收入计算。
- 招募按钮不再被通用刷新函数写成“升级”；深色主题下的商品说明使用主题文字色。

完整商品与岗位说明见 [COPY-AUDIT.md](./COPY-AUDIT.md)。作者来信、唱片名称与风格简介、纪念卡装饰性标题，以及已经清楚的短状态保留。

## 兼容性

- 发行版本为 1.3.2，存档格式仍为 7，可继续读取旧存档。
- 与 5933b40 对比，98 项主商品、40 件装扮和 5 种环境仪器的价格、前置、重复规则、效果数据完全一致。
- 岗位收入继续叠加基础收入；岗位数量、个人技能、红包奖励、生产、电力与前台运行规则不变。
- 购买确认设置、建造选址、室内归属和已购资格保留；没有恢复试用或试听。
