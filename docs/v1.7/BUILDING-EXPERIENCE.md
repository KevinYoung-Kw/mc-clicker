# V1.8.0 · 建筑操作统一

2026-09-10 · 原 alpha.16 本地验收通过，按用户确认归入 V1.8.0 正式发布；发布状态见 ../../DEPLOYMENT.md。沿用现有像素工具与选址条，不改生产规则，不增加另一套建造面板。

## 核查与本次改动

| 对象／操作 | 核查结果 | 本次处理 |
| --- | --- | --- |
| 邮箱 | 底层能搬动，但入口藏在邮政页下方 | 来信和邮政共用的顶部一行放定位、扳手；保持读信区域可滚动 |
| 直播间外景 | 点建筑直接进室内，缺少搬动整栋建筑的入口 | 室内管理面板上方提供外景定位、搬动；免费，取消回到室内；室内设备和供电设置保留 |
| 其他实体设施 | 已有详情页定位／扳手；物流和电力入口可从设施详情打开 | 逐项检查入口，不重复新增工具。唱片机迁入室内后仍按室内设备调整 |
| 住宅 | 能搬动转向，没有连续建造；开始搬动却未选原位置 | 住房页和选址条共用连续开关；搬动先选原址，就地旋转后确认 |
| 园艺布景 | 有连续布置、清除／收回与撤销 | 保留；搬动先选原址，继续限定从园艺台操作，防误触 |
| 朝向 | 新放置一律朝向 0，重复建造需要重转 | 建筑、住宅、布景、室内物品分别记住上次确认建造的方向；取消或搬动不改建造偏好 |
| 旋转 | 已有旋转图标 | 电脑选址增加 R；输入框、快捷键组合及墙面固定物件不拦截。仍以点击合法位置／确认按钮完成放置 |
| 连续消费 | 土地和布景已支持逐次确认 | 住宅复用；每建一座清空落点，按最新价格或已领库存结算；不足时给差额，退出不撤销此前完成的建设 |
| 收回 | 空地及已购布景支持免费回摆 | 不将其混为生产设施或住宅收回；这两项仍在候选池，需要安置、库存和线路规则 |

## 教程与旁白

- 「购买与建造」说明连续扩地、连续住宅与园艺布置、退出规则及默认朝向。
- 「搬动与转向」说明邮箱／直播间的工具位置、原地转向、R 和住宅／园艺管理入口。
- 「存档与读档」明确：桌面右上角设置；手机右上角菜单 → 设置 → 存档与读档。图片保存、长按、更新图片、核对读档与原图保留均说明。
- 存档旁白：游玩至少八分钟，开场朋友介绍结束，等待空闲，讲一次。
- 建筑旁白：已有两座住宅，游玩至少十分钟，在空闲间隙讲一次。服从同一队列，不挤入开局；允许跳过，不要求打开页面。
- 游戏内 V1.7 日志合并重复存档压缩说明，以玩家能使用的功能分组；技术过程仍保留在 CHANGELOG 和研究记录。
