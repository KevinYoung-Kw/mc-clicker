状态：2026-09-09 随 alpha.8（`a9c6f84`）发布，GitHub 与云端已同步。本批不改变购买价格、收入、岗位或存档格式。

## 玩家流程

| 阶段 | 第一次玩 | 之前玩过 |
| --- | --- | --- |
| 开局 | 旁白询问「第一次玩这个游戏吗？」；两个按钮在原旁白条内，无模态遮挡 | 同一处选择 |
| 10 颗绿宝石 | 保留抓捕、飞入商城、救出通知的剧情 | 跳过抓捕，通知仍按 10 颗购买；商品也不再描述被抓 |
| 购买通知后 | 原有感谢、介绍朋友、目标追踪等依次继续 | 跳过介绍；设置、分享可直接用，世界信息仍需购买通知 |
| 买到村民 | 村民介绍之后，补一条操作指南提醒；已经分配工作也不漏掉 | 不推新手教程提醒 |
| 找教程 | 黄框标世界信息；手机先标菜单，展开后标世界信息 | 随时自行打开指南 |
| 打开指南 | 直接显示「村庄与岗位」图解，标出操作指南页签。点开即记录完成，可以立即关闭 | 正常查看 |
| 后续 | 继续现有条件驱动的讲解与吐槽 | 过滤 guide / explain 类基础教学，保留事件、行为反应、闲话与互动 |

本批采用最新的「村民 / 岗位阶段提醒」位置，取代此前讨论但未实现的「目标追踪之前先打开教程」。

提醒文案按用户定稿更新为：「如果你还想知道更多内容，我这里还有一本操作指南，这可是家传秘诀。你要想看的话，可以去那里了解一下。」按钮仍为「打开操作指南」。「家传秘诀」短句用低一点的声调，见 [新旧试听](qa/narrator-prosody/index.html)。

## 提醒的边界

- 不把「出现过字幕」当作「看到了教程入口」。字幕只说一次，未打开时保留入口黄框和安静时的小提示。
- 黄框短暂闪两次后静止；减少动态模式不闪。旁白按钮、入口小提示不同时显示，避免重复。
- 不阻止采集、购买或继续建造。不要求读完、停留若干秒或点击下一页。
- 已经自行打开过操作指南的玩家不再收到重复入口提醒。
- 不因买得快、岗位已安排、打开菜单太久而过期；购买回执、选址、后台和遮挡仍按原有规则让位。
- 主动暂停旁白时，不用「必然提醒」强行恢复声音、字幕或高亮。声音静音则仍保留文字提示。
- 选择及访问记录随存档保存。旧存档不弹新的开局选择、不补播这条新提醒；仍继续各自原有进度。

## 实现与验证

`openingChoice` 区分 pending / first / returning / legacy；`manualPrompted` 表示已经发出提醒，`manualVisited` 表示真正打开了指南。没有新增计时器或经济循环。

- `npm test`：619 / 619 通过，含新开局、跳过、重载、旧档、快速购买、提前就业、长时间菜单遮挡、点开即完成与旁白语气的场景。
- `npm run build`：通过。原有大型打包分块警告仍在。
- 浏览器使用隔离存档与生产构建：Chromium 1440px、WebKit 390px、Chromium 320px。覆盖实际购买、抓捕动画、菜单高亮迁移、教程定位、关闭与刷新；无页面脚本错误和横向溢出。
- 另查键盘选择与全屏村庄面板的进入、返回和通知空位回收。测试不等于物理手机实测。
