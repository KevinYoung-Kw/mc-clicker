## 本轮图片统一

保留已经确认的单主题阅读页面，只调整图片。所有图解采用 640 × 416 的同一构图基准，导出 1280 × 832 的 WebP；使用游戏纸色底、细分隔线、绿色步骤号和棕色点击框。

- 界面控件统一按 1.4 倍拼图，44px 的按钮不再在不同图中忽大忽小。
- 原始界面以 4 倍像素密度重新截图，最终缩小输出，不拉大低清文字。
- 截图保留完整文字行和按钮边界，建造图完整展示落点边界，室内图保留完整房间。
- 数字、长解释不重复塞进图中；必要规则仍为可读、可访问的 HTML 文字。
- 3D 场景允许按主体取景，保证模型完整；不为了机械统一场景缩放而让教学目标变小。

## 复现与维护

来源是当前代码在隔离浏览器中的真实界面，复用 `docs/v1.6/qa/stability-baseline/fixtures/peak.json` 裁剪出的教学存档。截图脚本只修改隔离上下文，不操作玩家的存档。

```sh
npm run dev -- --port 8917 --strictPort
uv run --with playwright scripts/tutorials/capture.py
uv run --with playwright --with pillow scripts/tutorials/render.py
npm run build
npm run preview -- --port 8918 --strictPort
uv run --with playwright scripts/tutorials/verify.py --url http://127.0.0.1:8918/ --production
uv run --with playwright scripts/tutorials/verify-variants.py --url http://127.0.0.1:8918/
```

先完成截图，再运行拼图。`capture.py` 禁用隔离页面的开发热更新连接，避免生成图集时重载正在操作的游戏。更改按钮、名称或流程后重新截图；`render.py` 检查裁剪区域和标注目标没有越界。实际资源通过 Vite 指纹 URL 引入，替换图片会刷新缓存。
