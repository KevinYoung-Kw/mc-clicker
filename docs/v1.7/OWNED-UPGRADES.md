# 商城升级分类与排序

状态：随 V1.7.0-alpha.7（`b8517d3`）发布。云端状态见[部署记录](../../DEPLOYMENT.md)。

## 修复范围

- **扩地**：原角标已排除土地，但已购列表仍把无限次购买当作无限等级。现在两处使用统一分类，土地不进入可升级或已完成设施列表。保留「扩地 +」、首次开垦、选址、连续扩地及原价格，详情使用「片土地」而非「级」。推荐升级组件也不生成「升级开垦」。
- **设施排序**：满足条件的放在前面，各组按本次价格升序，同价沿用目录顺序。依据购买状态区分前置、人口和住房限制；不会按当前余额反复重排。
- **价格口径**：本体未满级时使用卡片购买按钮的实际本体升级价；邮政使用下一等级费用；本体满级时，使用尚未购买、已解锁改造中的最低价。若只剩锁定改造，则放到后面。满级但仍有改造的卡片显示价格及改造入口，不再只显示本体完成。
- **设施内改造**：可用与待解锁分组分别按下一次改造费用排序，修复按初始价格排序导致的多级改造顺序错误。例如风车已安装一级宽面叶片后，依次显示齿轮箱 10,000、宽面叶片 15,600、发电线圈 18,000。
- **操作稳定性**：收入刷新只更新金额和购买状态。购买后才按新价格重排；保留原确认流程、展开项、滚动锚点和桌面焦点。已满级项目继续归入已完成。

没有调整价格、生产、收益、解锁条件、土地规则或主存档格式。
