# V1.5.2 · 入口到场后才出现

修正 V1.5.1：此前按钮开局就可见，动画只起介绍作用。新开局隐藏设置、分享、信息及手机菜单；买出消息通知、播完获救回应后，介绍三个入口。

> 先把设置、分享叫来，最后给我也留个位。

设置 → 分享 → 通知自己的纸片头像，依次飞入，间隔 170ms。每枚飞行 800ms，到达后才显出并启用对应按钮；设置到达时，手机菜单和免费操作指南一并可用。最后出现的信息入口使用纸片头像，包含原有眨眼、封嘴与领结。

为避免入口到场时把下一枚的落点挤走，飞行期间临时预留不可见的位置，并禁止聚焦、点击。飞行以外没有隐藏占位。手机菜单未展开时，图标飞向菜单的位置；不强制打开菜单。

分享、设置随通知一起获得，无额外价格。基础采集说明和购买失败原因仍默认提供。

介绍完成状态随存档保存。刷新、中断、切后台或调整窗口大小后补齐已获得入口，不重播、不遗留隐藏按钮；减少动态直接显示。旧存档保留原有入口。存档格式仍为 7；新加的 `companionsVersion: 2` 仅区分这次开场规则，不改变生产或收益。
