# V1.6.0-alpha.2 · 住房首批与布景修复

2026-09-08。接入已经验收的八种房型，使用游戏原生模型、像素材质和昼夜窗灯。当前交付范围是住房玩法及布景缺陷修复；整版大世界性能、真机手感及 CF25/26 面板问题仍需后续处理。

## 首位村民与住房

1. 首位村民无需先有房，按原条件购买。购买后获得一次安家礼资格，不在地图上自动生成房屋。
2. 在「村庄 → 住房」点击 **0 ◆ 领取**，取得橡木尖顶屋并进入手动选址。
3. 领取后取消或刷新，小屋保留在待建列表。确认位置才建造，赠品不扣绿宝石。
4. 建成后给村民分配独立门牌。此后招募同时检查空住址、原土地／服务条件和 24 人硬上限。
5. 住房页可以查看住户、定位、搬移和安排入住。搬家不改变岗位、技能和收入；取消搬动保留原房屋。多人房屋中每位居民有自己的门牌。

## 空间与旧档

- 独立 `housing` version 1：住宅实例、库存、领取状态和住址分配；主存档版本与键不变，仍为 7。
- 原有且可见的自动村屋按原位置、比例转为可管理的「原有村屋」。以后扩地、招募都不自动补房。
- 旧档已有居民、岗位、技能、货物和收入保留；缺房显示待入住，不停止已有村民工作。旧档也可领取一次首栋安家礼。
- 保存实体与预览使用相同尺寸和旋转；庭院、回廊采用实际墙体碰撞。确认前检查门口可达、村民绕行路线，以及扩大岛屿后的大体型通道。
- 首片 5×5 土地允许建下免费小屋。住宅不参与工业产能和物流收入计算。
- 若修复存档时发现住宅与已有设施冲突，保留为待建住宅，允许免费重新选址。

## 布景修复

旋转缺陷来自刷新选址信息时误执行了旋转操作。现在信息更新不改变方向；只有点击旋转按钮才转 90°。主世界布景、住房和直播间仍使用同一个确认区。

新购主世界土地各自保存生成种子：树木数量、高低、朝向、位置以及花草组合变化，避免整齐重复的固定点位。生成结果跨刷新保持一致；已有旧土地不重新生成，已清理对象不复活。园艺清理与摆放入口保持不变。
