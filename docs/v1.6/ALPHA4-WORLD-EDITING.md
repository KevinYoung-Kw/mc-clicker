# V1.6.0-alpha.4 · 连续布置与建筑转向

2026-09-09。已随发布提交 `c030270` 推送 GitHub 与云端，标签 `mc-clicker-v1.6.0-alpha.4`。[公网核验](qa/alpha4-live/deployment.json)与[正式入口操作回归](qa/alpha4-live/editing/report.json)已通过。本轮不再修改设施价格、铁路时机或生产收益。

## 操作与规则

| 功能 | 入口与操作 | 保留的行为 |
| --- | --- | --- |
| 连续扩地 | 商城 → 扩地；打开「连续」，点浅绿色边缘，再确认 | 每片单独预览、报价、确认和落成；买完清空旧落点，保留世界、镜头和工具；完成返回原面板 |
| 空地整理 | 扩地操作栏 → 扳手「整理」；选已购土地，再收起 | 收起为同世界库存，不退绿宝石；后续扩地先免费使用库存。历史地价与累计建设成果不回退 |
| 园艺连续布置 | 园艺台 → 布置；打开「连续布置」 | 品种和朝向持续保留，每件重新选址确认；逐次扣款或使用库存，不自动占用新位置 |
| 园艺连续整理 | 园艺台 → 整理 →「到世界整理」 | 点实际布景，清除自然植物／收回已购布景；扳手搬动。确认或取消搬动后直接选下一件，独立于种植开关；有撤销和完成 |
| 建筑朝向 | 设施详情顶部扳手 → 旋转图标 | 原地 90° 转向或边搬边转；预览与实际占地一致，确认才保存，取消不改原建筑 |

土地与园艺的连续偏好分别记忆。普通单次购买仍按原方式返回原面板；跳过购买二次确认的设置不跳过空间选址。沿用原像素图标、分隔行、按钮、绿色可用面、红色无效提示和主题变量；手机操作区按内容高度适配，不增加卡片或第二个抽屉。

空地保护包含：

- 各世界起始地块与传送入口；跨边界的设施完整占地及通行间距；住房；已购买的地表、花草和树木。
- 移除后不能割裂大陆、现有村民通路，或使现有供电／运输失去可达路径。线路可在保留端点的前提下绕行。
- 有村民或铜傀儡正经过的地块暂不能收起；室内工作人员与未显示的储备居民不误挡户外操作。
- 自然布景随地块保存，包括已清除状态；回摆或刷新不重新抽取树木。收起可撤销，已用掉的库存不能再次撤销复制。

本轮没有加入生产设施拆除、框选清除、自动连续付款或跨世界互换土地库存。

## 数据与模型

主存档仍为版本 7、原 localStorage key。增加可选 `land` 账本与 `editing` 偏好；旧档由当前土地推导已购数量，不补扣费用。新账本分别保存三世界历史购买数、已收地块及自然布景快照。返回旧版本前应保留导出存档，旧版不理解这些新增字段。

建筑沿用 `placements[id]`，增加可选的四分之一圈 `rotation`；无该字段即原方向。先按原始模型规格适配尺寸，再旋转，因此长方形建筑不会因转向而变瘦或悬空。碰撞占地、麦田通道、村民工作位置、直播间门口与线路节点读取同一个朝向；升级保留朝向与岗位，货物和基础收入不重置。

连续扩地与空地整理保存世界坐标下的镜头位置和尺度，抵消大陆边界改变导致的自动中心／缩放变化。整理结果不会以镜头动画帧率影响收益。

## 验证

规则验证覆盖历史地价、三世界库存隔离、重复确认与重复撤销、核心土地／跨地建筑／住房／布景／在途货物保护、自然布景恢复、旋转模型包围盒与贴地、旋转后真实农民工作和存档恢复。另将既有旁白节奏测试改用固定地形种子，避免系统时钟改变彩蛋可用位置而偶发失败；不修改游戏彩蛋规则。

浏览器使用正式构建和独立测试存档，通过真实点击／触控完成：连续扩地五次、收地／撤销／免费回摆、设施原地转向与取消、连续摆放五件已转向绿篱、地图整理／撤销／搬动／返回与刷新。覆盖 Chromium 1440、WebKit 390、Chromium 320；报告与截图见[浏览器结果](qa/world-editing/report.json)。测试不修改真实玩家存档，正式构建不暴露调试接口。
