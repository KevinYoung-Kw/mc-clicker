# 新功能的 UI 收敛检查

适用网页和小红书。新增功能先找已有入口与组件；这份清单用于修改后的复查，不是另做一套设计系统。

## 先确定放在哪里

| 玩家要做什么 | 现有入口与复用方式 |
| --- | --- |
| 找下一件新东西 | 商城「发现」；升级放「已购买」，不重复铺满发现 |
| 看完整收藏和建设 | 图鉴「建设／特性／成就」；设施家族筛选只属于建设 |
| 修改某座设施的工作方式 | 点世界中的设施或已有设施条目，直接在详情操作；不要只给另一个管理页的跳转 |
| 判断哪里出问题 | 村庄经营概况／工业生产与积压；黄色较弱、橙色受阻、灰色待机，并写真实原因 |
| 查看全村状况 | 全村生活：幸福来源、各设施当前选择和总费用；具体伙食、饮品、活动在各自设施设置 |
| 升级、定位或整理 | 复用购买确认、设施升级行、定位／扳手／收纳图标，保留可访问名称 |

## 每次涉及 UI 的更新都过一遍

1. **入口闭环**：从世界物件和管理列表都能找到操作；返回文字、原页签与原滚动位置正确。分点也进入所属设施，使用同一份选择数据。
2. **信息层级**：首屏先看当前状态和能做的动作。不同内容进明确子页，移除重复长列表、重复按钮和无用说明。保留真实价格、代价、受阻原因与必要的作用范围。
3. **现有样式**：沿用管理页签、单行分隔、像素图标和主题变量；最多一层分组。不要为新功能另造大按钮墙、层层嵌套卡片或新配色。
4. **稳定更新**：倒计时、费用和选中态只更新字段。点击切换选项、后台刷新后，焦点与滚动不跳。切页不重播整个面板的入场动画。
5. **实际屏幕**：至少看桌面、320px 和 390px；覆盖默认、末地、麦金塔主题。检查触控目标、换行、底栏遮挡、空状态、缺钱、未解锁、满级、收纳和旧档。触控不依赖悬停；键盘能切换页签、执行和返回。
6. **证据与范围**：存同场景截图，实际操作一次购买／取消／设置／返回／刷新。与权威规则核对，没有经济改动就明确写出；不要用 UI 注资样本证明回本或节奏。分别记录两版结果与未测范围。

## 本轮参考与维护边界

- 图鉴呈现：`src/atlas-ui.js`；分类状态、键盘操作与滚动恢复由 `src/main.js` 接入 `panel-memory.js`。
- 成就呈现：`achievements-ui.js`；条件/进度共享 `achievements.js`，用主题色、平铺分隔行和局部刷新。新解锁不移除正在操作的行，筛选时再收起。
- 生活呈现：`src/village-life-ui.js` 的 `facilityMarkup`、`lifeMarkup` 与局部 `refresh`。菜单仍调用 `life-menu.js`；供餐、费用与幸福分别由原模拟模块计算。
- 复跑：`scripts/verify-alpha7-ui.py --url <本地地址>`，小红书加 `--xhs`，正式构建加 `--production`。使用隔离样本，不覆盖玩家实际存档。
- 改动公共 UI 同步双版；`main.js` 保留平台差异，不能整份覆盖。发布与历史存档仍执行 `docs/RELEASE-CONTRACT.md`。
