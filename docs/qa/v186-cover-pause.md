# V1.8.6 开始封面与暂停页打磨

状态：同一未发布候选批次的视觉改进，已本地验证；未推送、未部署、未提交小红书审核。

## 改动

- 小红书开始页使用本游戏住房、风车、麦田、树木和村民模型离线渲染的透明 WebP。1200 × 1000，共 137242 字节。没有新增运行时 WebGL 场景、联网素材或模型动画循环。
- 手机单列、桌面与手机横屏双列；开始按钮保持独立，加载时禁用，加载完成后可用。减少动态偏好下停止加载动画。旧内核不支持 min/clamp 时保留尺寸回退。
- 两版暂停状态都保留玩家当前世界，中央显示休息表情、返回说明和收益暂停状态。只是状态呈现，原有前台判定、存档和生产计算不变。
- 手机全高菜单暂停时不占通知预留槽，避免插入大片空白；回到游戏仍自动继续，不增加一次关闭弹窗操作。
