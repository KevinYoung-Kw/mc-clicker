## 改动范围

- 邮箱：两个页签与三个设施工具仍在一行。工具保留 44px 点击区域；400px 及以下移除重复的页签图标，保留名称、来信数量与完整 Lv.n。其他宽度也禁止数字拆行。
- 装扮：收纳按钮明确为 44×44px 图标按钮；手机标题和余额上下排列，为收纳与关闭各留独立位置。装扮摊等级同时禁止拆开 Lv.n。
- 小红书：装扮／分享弹窗的固定关闭按钮同步移到安全区下方，修复只移动弹窗、按钮仍停在屏幕顶端的遗漏。
- 性能：装扮刷新仅在文本／状态变化时写 DOM，单次刷新复用面板根节点查询。没有更改模型、分辨率、帧率、阴影、经济数值或存档格式。

## 小红书启动与前台规则

HTML 自带不依赖主游戏 JS 的方块加载指示。主模块完成、世界初始化后再启用「开始游戏」。未点击前不推进游戏模拟、不计算收入，也不显示误导的「已暂停」旁白。加载等待不算离开游戏，不产生回来后的缺席对话。

开始按钮按每次页面访问管理，不写入存档；刷新会再次进入开始页，已有进度继续读取。重复点击不会重复创建游戏循环。减少动态模式下不播放加载跳动。渲染失败时保留进入设置／存档的退路。

触屏／小红书容器显式开始后，以页面可见性及 pagehide/freeze 生命周期判断是否运行，不再因原生按钮占用 DOM focus 而假暂停。hidden、pagehide、freeze 仍停止收益，返回时重置时钟，不补离线收益。桌面焦点暂停与原网页版规则保留。没有添加“后台照常赚钱”。
