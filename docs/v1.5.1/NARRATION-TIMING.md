# V1.5.1 · 前期多说一点，说在事情发生时

状态：本地实现与验证完成，尚未发布。基线为 V1.5.0（源码提交 `4f51ca4`）；不调整价格、收益、购买条件和后台暂停规则。

## 这次先核查到的断点

- 旧规则：20 秒买到 3 种设施，就说“原来是老手”，并跳过包括邮箱、派工在内的一批介绍。
- 木镐的旁白已退役；仓储、红石虽然有评论，但没有交代下一步操作。
- 新的普通评论会淘汰较旧的普通评论；连续建设时，不适合用这一类承载机制说明。
- 离开游戏只显示暂停状态，回来没有解释为什么没有后台收入。
