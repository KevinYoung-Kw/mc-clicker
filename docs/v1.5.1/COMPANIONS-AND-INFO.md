# V1.5.1 · 通知的两个朋友与世界信息

本补丁与前期旁白节奏调整一起发布；不改变存档格式、收益和商品价格。

## 开场顺序

| 时点 | 表现 | 限制 |
| --- | --- | --- |
| 买出通知，收据结束 | 原有获救回应 | 保留用户喜欢的商城吸入动画 |
| 获救回应结束约 1 秒 | “对了，再介绍两个朋友：分享、设置。” | 一句话，约 3 秒；不增加购买环节 |
| 介绍结束 | 两枚带名称的像素图标错开 170ms 弹出，沿曲线飞入入口，落点出现像素亮点 | 单枚飞行 800ms；不挡点击、不移动镜头、不播放未解锁声音 |
| 随后 | 原有目标追踪推荐 | 已买目标追踪则跳过推荐 |

桌面飞到分享、设置按钮；手机菜单收起时飞到可见的“菜单”，已展开时飞到实际按钮。不自动展开菜单。分享和设置从开局就免费可用，动画只负责介绍。

介绍完成即保存。刷新、后台、缩放窗口、开关手机菜单均不重播；进行中的装饰动画可取消，减少动态模式直接略过。旧档已购买通知的玩家不补播开场，新档在介绍途中刷新可继续这一句话。

## 世界信息

- 原创纸片头像、值班状态、一句简介。
- “世界近况 / 操作指南”两个平面页签；单行分隔，无嵌套卡片。
- 指南只列已拥有系统；近况采用固定宽度的在线时间列。
- 暂停／恢复旁白、邮箱、返回使用轻按钮；四套界面主题保持相同层次。
- 免费操作指南及实际收入页面保留原有入口与功能。

## 第一次禁言

设置与世界信息调用同一个开关。第一次从开转关，显示封嘴像素表情、短促微动和“呜——！”；下行说明“旁白已暂停”，1.8 秒后消失。不播放音频。

关闭后，世界信息头像和顶部入口显示封嘴状态。已经开始的旁白停止，恢复时不接着念被打断的半句话。首次反应标记随存档保存，反复开关不反复打趣。领结配饰与封嘴表情可以同时保留。

购买、建造、失败和前台暂停仍使用统一通知栏，不受“暂停旁白”屏蔽。
