## V2.0.0-alpha.8 · 成就册

2026-09-14。网页已部署腾讯云：提交 `6caddc6`，标签 `mc-clicker-v2.0.0-alpha.8`。小红书源码 `3a44aed`、标签 `v2.0.0-alpha.8-xhs.1` 及离线包已同步，未提交平台审核。

- 16 → 30 枚成就，直接显示条件、进度和相关设施入口。
- 分为成长、经营、收藏、挑战，可筛选未达成项。
- 新增「基础村屋安顿居民」「三位农民各有一块田」「三世界植物花园」等挑战，老存档也能补做。
- 建设全解锁、全成就分别统计；已经获得的成就，搬家或换岗后不会丢失。
- 设计参考 Factorio 的玩法限制挑战和 Minecraft 的操作与趣味进度，沿用现有像素风与分隔列表。
- 奖励为永久成就记录，不增加经济倍率；旧成就保留，补做后调整布局也不丢失；导入不连播成就提示。网页与小红书同步。两版测试 848／853 项通过。验证见 `v2.0.0/ALPHA8-ACHIEVEMENTS.md` 与 [发行核验](v2.0.0/qa/alpha8-release/README.md)。

## V2.0.0-alpha.6 · 从广播到直播（网页版已部署，小红书源码与离线包已同步）

- 工业研究后可研究广播（8K），开办电台（24K）、添置主持席（6.4K）。电视与流媒体依实际工业建设逐步开放，现代保留订阅、联动节目与自动导播；不直播仍可独立推进。
- 广播、电视、流媒体分别采用 180／450／1,000 的受众阶段上限，现代沿用世界建设带来的容量。收入和观众增长随阶段提高；礼物收益同步校准。电台两次扩建为 192K、1.536M，避免入口降价带来整条升级线过早买满。
- 同一个房间新增紧凑阶段说明和对应研究入口；广播使用“听众/收听”，机位及互动随阶段开放。设备页只列当前和下一步，所有已购设备继续保留。
- 旧档已有直播间、已完成或已付费广播研究保留原有频道成长与设备权益；未完成的旧研究继续保留进度，不提前完成。新增 live.broadcastVersion / legacyBroadcast 随 JSON、存档码及图片保存；schema10 和冻结字典不变。
- 成果与限制见 `docs/v2.0.0/ALPHA6-BROADCAST.md`。2026-09-14 已完成本批同步；网页版已部署，小红书源码与离线包已同步，详见 docs/v2.0.0/qa/alpha6-release/README.md。

## 更新记录维护规则

1. 同一开发线每交付一批可发布修复，增加一次 `alpha.N`；不把每次保存文件算一版。补丁稳定后使用 `1.7.1` 等正式版本；新需求立项另定次版本，不为插入修复反复顺延所有排期。
2. `package.json` 是版本号唯一来源，同步锁文件；页面和设置读取现有 `release.js`。游戏发行版本与主存档格式分开，修 UI 不升级存档格式。
3. 升号时在本页顶部增加一条记录，说明新增、修复、规则变化和未完成范围。`tests/release.test.js` 检查当前版本是否有对应的最新记录；历史条目保留，错误记载注明更正。
4. 每项群聊反馈先核查现状。已实现的关闭，确有缺陷的复现后修复，新需求先写范围、依赖和验收。不能把“待建库存”写成“已建房屋可收纳”，也不能把入库修复写成新增自动采集。
5. 本地验证后标“本地已修”；实际推送与公网核验完成后才标“已发布”，填写提交／标签及部署证据。只整理文档不升游戏版本。
6. 按最新要求，版本日志接入世界信息页，不另外发送教程邮件。大版本摘要同步维护 `src/version-history.js`，保留本文的逐批修复证据；计划和未发布功能不得写成已上线。
