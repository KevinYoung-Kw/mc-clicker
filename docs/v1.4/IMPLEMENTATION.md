## 发布前界面打磨

- 主世界与直播间主菜单支持再次点击选中项收起；快捷键 1–4 同样切换，长按快捷键不会反复开关。程序内部跳转仍只负责导航，购买、前置跳转不会误收起菜单。
- 收入数字与明细组成一个完整触控按钮；加大像素下拉标记，手机保持 60px 单行顶栏。收入弹窗按来源对齐，保留真实到账口径。
- 村庄／工业商品卡标题与购买同排，说明、状态和操作使用全宽；主分类栏固定在面板滚动区顶部，次级选择不叠盖主分类。
- 人物定位、世界全景与线路查看统一使用像素地图标记。新模型图标随发行版本更新资源地址，避免旧缓存混用。
- 沿用四套网页主题、购买确认、选址、存档和现有画质。手机关闭菜单后恢复原自由视角；室内关闭菜单仍留在房间。

## 当前玩家流程

**电力**：建好设备 → 点“接入电网” → 看见实际运行/缺电/满仓状态。电源共同供能，设备仍遵守原有线路范围和损耗。首次接入后可开启免费自动接入，也可一次接入全部合法设备。缺电不会删除已保存的连接，搬动建筑后自动重新找路。
- **物流**：在储物箱的物流调度中选货源 → 安排已有村民优先取货 → 观察交货点和待运货物。优先货源没有任务时继续搬运其他货物；取消优先仍保留搬运岗位。抱着货物时先完成交付再调整。村民基础 B 不减，交货本身不重复加钱，销售仍使用原账本。
- **自动化**：用“＋／−”分配已购买的发射器。固定名额保持不变，侦测器只借用空闲名额；已开始的人工任务先完成。音乐演出、主持与唱片播放仍分开。

控制台和储物箱直接点模型即可打开对应管理页，工业页也能到达同一功能。线路图仅在需要时打开，按真实位置显示；拖动/双指缩放不重建整个面板。手机保留底部菜单和退出，恢复原世界镜头。

## 相比参考稿的取舍

- 没有新增任意配送起终点、自由电线编辑、独占车辆或分区电网。工业运输仍按区域结算，线路图不声称逐条独立结款。
- 铜傀儡显示取货范围；不将现有自动找货描述为按编号循环。仅收事件模式下，点“加入巡收”会同时启用货物收取。
- 基础储物箱不要求接电，电动改造才进入待接清单。唱片播放与手动演出不增加接线手续；旧档主动停用的唱片机仍可在室内恢复。
- M5 前置由 T7＋M4 改为 T7；M11 由 M10 改为 M5。价格不变，M14 的原有前置保留。
- 暂停自动装卸会移除它的运输加成；停用漏斗仍保留售货箱的基础交货；铁路对下界的运力增益对应当前运行。
- 本次保留四个主要模型改造：M4 的货箱/调度牌与货架，M5 的电路台/曲柄/控制模块，M7 的传动与发电底座，M15 的成组线圈/转子。其他设施修状态，不重做整套美术。
